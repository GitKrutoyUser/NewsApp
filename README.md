# WorldPulse

## Краткое описание курсовой работы

**WorldPulse** — настольное приложение-агрегатор новостей с интерактивным 3D-глобусом. Пользователь выбирает страну непосредственно на глобусе и получает связанные с ней новости. Для каждой статьи отображаются заголовок, описание, дата, изображение и ссылка на источник. Новость можно открыть во встроенном режиме чтения с загрузкой полного материала через API или HTML-резервный механизм.

Приложение предназначено для быстрого просмотра мировых новостей в едином интерфейсе. Оно также содержит лунный раздел с новостями о космической тематике и визуальный звёздный фон.

## Как работает приложение

1. `NewsService` обращается к FreeNewsAPI и получает русские и английские новости за последние 24 часа.
2. Результаты проходят нормализацию: проверяются URL, страна, язык, дата, описание и изображение.
3. `NewsRepository` сохраняет материалы в локальную базу SQLite. Дубли удаляются по URL и заголовку, а новости без описания не сохраняются.
4. При выборе страны приложение сначала показывает кэш. Если материалов меньше пяти, выполняется отдельный запрос по выбранной стране; при необходимости используется период до семи дней.
5. Новости отображаются постепенно и постранично, поэтому интерфейс не блокируется загрузкой всего списка сразу.
6. Фоновая синхронизация обновляет кэш примерно раз в час, а ручной интервал настраивается в `.env`.

## Архитектура и технологии

- **.NET 10** и **Avalonia UI** — кроссплатформенный графический интерфейс.
- **MVVM** и `CommunityToolkit.Mvvm` — разделение интерфейса, состояния и логики.
- **SQLite** с ручным SQL-кодом — локальное offline-first хранение новостей; ORM не используется.
- **FreeNewsAPI** — получение новостей и материалов статей через REST API.
- **Custom DrawingContext** — интерактивный глобус с проекцией географических координат, вращением, масштабированием и выбором страны.
- **WAL и индексы SQLite** — более быстрые чтение и запись локального кэша.

## Запуск

Требуется установленный **.NET 10 SDK**.

```bash
git clone https://github.com/GitKrutoyUser/NewsApp.git
cd NewsApp/NewsApp
dotnet restore
dotnet run
```

Готовый файл `NewsApp/.env` уже находится в закрытом учебном репозитории. Через него можно менять размер страницы API, количество страниц на язык и минимальный интервал ручного обновления.

Подробные UML-, ER-диаграмма и схема базы находятся в каталоге [`course_materials`](course_materials/).

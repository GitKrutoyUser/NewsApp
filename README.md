# WorldPulse / NewsApp

Готовая основа курсового приложения-агрегатора новостей на **.NET 10, Avalonia UI, CommunityToolkit.Mvvm, ADO.NET и SQLite**.

## Важно про Entity Framework

Пакеты Entity Framework сохранены в проекте как часть исходного фундамента. Код приложения их не использует: база работает через `Microsoft.Data.Sqlite`, ручные SQL-запросы с параметрами и транзакции, как требует техническое задание.

## Реализовано

Приложение загружает русскоязычные новости через рабочий JSON-эндпоинт `https://freenewsapi.ai/v1/search?lang=ru`, фильтрует записи с `lang=ru`, получает изображение из поля API и дополнительно ищет `og:image` на странице оригинала. HTML корректно читается в UTF-8 и Windows-1251.

Новости сохраняются в `world_news.db` в пользовательской папке данных `WorldPulse`, чтобы Windows не блокировал запись, если приложение находится в `Program Files`. При выборе страны интернет не используется: данные берутся только из SQLite. Фоновый таймер обновляет ленту каждые 30 минут, а при отсутствии сети приложение продолжает показывать последний кэш.

При запуске сначала показывается локальная база. Время последнего обращения к API также хранится в SQLite, поэтому перезапуск приложения не сбрасывает ограничение: автоматическое обновление и кнопка «Обновить» не выполняют новый запрос чаще одного раза в 30 минут. Новые записи добавляются по URL без дублей.

На новом устройстве приложение сначала создаёт папку и файл базы, затем выполняет первичную загрузку новостей. Пока база пустая, ограничитель 30 минут не мешает повторить первичную попытку. Если API временно вернул пустой ответ или сеть была недоступна, следующий запуск повторит заполнение базы.

В левой части окна используется вращаемый интерактивный глобус. Его границы взяты из публичного набора Natural Earth `ne_110m_admin_0_countries.geojson`; глобус можно перетаскивать, а клик по стране переключает локальную выборку новостей. API `freenewsapi.ai` отдаёт ISO-код страны не для каждого источника, поэтому статьи с неизвестной страной относятся к разделу «Мир», а не ошибочно приписываются России.

## Сборка

Откройте `NewsApp.slnx` в Visual Studio с поддержкой .NET 10 или выполните:

```bash
dotnet restore NewsApp/NewsApp/NewsApp.csproj
dotnet build NewsApp/NewsApp/NewsApp.csproj
dotnet run --project NewsApp/NewsApp/NewsApp.csproj
```

Для запуска нужен .NET 10 Desktop Runtime и системные зависимости Avalonia для вашей ОС.

## Структура

`Models` — модели новости, страны и DTO API. `Data` — чистый ADO.NET-репозиторий SQLite. `Services` — HTTP API и HtmlAgilityPack. `ViewModels` — команды, кэш, таймер и офлайн-режим. `Views` — разметка главного окна и карточек.

## Обновление GitHub

После изменений выполните из корня репозитория:

```bash
git add -A && git commit -m "Обновление приложения" && git push origin main
```

Команда обновляет существующие файлы, а не создаёт копии. Каталоги Visual Studio, `bin`, `obj`, локальная база и архивы исключены через `.gitignore`, но локально не удаляются.
